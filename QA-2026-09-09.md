## P1 — giderilen/yeniden doğrulanan

- **Yeni düzeltme:** `DutarTunerPlugin.java` captureLoop içinde stopRecorder'ın ortak recorder alanını null yapmasıyla oluşabilecek null dereference, her iterasyonda null kontrollü yerel AudioRecord referansı kullanılarak giderildi. Stop/release sırası ve tuning algoritması değiştirilmedi. Build, unit/lint ve instrumented test tekrar geçti; yarışın cihazda deterministik üretilmesi yapılmadı.
- Önceki çalışma ağacındaki katalog HTML attribute kaçışları ve favori depolama bozukluğunda açılış düzeltmeleri regresyon testinden geçti.
- MainActivity'nin BridgeWebChromeClient kullanımı Capacitor dosya seçici/confirm davranışını koruyor; compile başarılı. Gerçek dosya seçimi/yetkili publish uçtan uca denenmedi.
- Worker boş/eksik ADMIN_TOKEN'u reddediyor; localhost admin yabancı origin ve simple POST'u reddediyor. Negatif testler geçti. Bu kaynak değişiklikleri canlı Worker'a deploy edilmedi.

## P1 — açık riskler / fiziksel doğrulama

1. Native stopRecorder recorder'ı thread join öncesinde release ediyor; ortak running/thread yaşam döngüsü geniş kapsamlı stres testi istiyor. Dar null düzeltmesi bütün eşzamanlılık risklerini çözmez. Hızlı start/stop, ekran kilidi, background/resume, ses kesintisi ve permission Settings dönüşü fiziksel cihazda test edilmeli.
2. Completion feedback reference-mute yolunu kullanmıyor. Fiziksel hoparlör sızıntısı, oktav/harmonik yanlış algılama ve completion tetikleme döngüsü sesli test bekliyor. Tuning eşikleri ve feedback tasarımı değiştirilmedi.
3. Cache metadata'sı remote kataloğu yerel katalog yerine kullanabilir; remote nota görselleri için kalıcı offline indirme veya viewer hata/retry görünümü yok. Uçak modunda görsel eksikliği mümkündür. Merge/cache davranışı ürün kararı gerektirir.
4. Browser fallback getUserMedia sonrası iptal kontrolü native yol kadar güçlü değil. Android native yolu için test sonucu web/iOS parity onayı değildir.
